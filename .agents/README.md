# The `.agents` directory

Contains various pieces of information designed to help AI agents in collaborating with developers
throughout the development lifecycle.

This directory uses the [dotagents] suggested structure and is compatible with [AgentSkills].

## Directories

| Directory  | Purpose                                                     |
|------------|-------------------------------------------------------------|
| [Personas] | Identities for an AI agent.                                 |
| [Rules]    | Requirements when working within the code base.             |
| [Skills]   | Guidance for performing certain tasks within the code base. |

[AgentSkills]: https://agentskills.io
[dotagents]: https://github.com/bgreenwell/dotagents
[Personas]: ./personas
[Rules]: ./rules
[Skills]: ./skills
